Position Interface Unit (POSIF)
PDL API Reference

General Description

Position Interface Unit (POSIF) driver for the PSC1M microcontroller family

The POSIF unit is a flexible and powerful component for motor control systems that use rotary encoders or hall sensors as feedback loop. It provides interface for motor position and velocity measurement. POSIF unit works with CCU4 and CCU8 to enable position and velocity measurement and to control PWM outputs using multi channel pattern.

Driver is divided in three POSIF functional blocks - Hall Sensor Control (POSIF_HSC), Quadrature Decoder (POSIF_QD) and MultiChannel Mode (POSIF_MCM).

POSIF driver features:

  1. Configuration structure Cy_POSIF_CONFIG_t and initialization function Cy_POSIF_Init() to configure global settings
  2. Allows to change the operating mode using Cy_POSIF_SetMode()
  3. Allows the selection of one of the four inputs (A, B, C or D) using Cy_POSIF_SelectInputSource(). In hall sensor control, inputs are hall0, hall1 and hall2 signals. For quadrature decoder mode, inputs are phase A, phase B and index signals.
  4. Hall Sensor Control (APIs prefixed with CY_POSIF_HSC_)
    • Configuration structure Cy_POSIF_HSC_CONFIG_t and initialization function Cy_POSIF_HSC_Init()
    • Update current and expected hall pattern in shadow register using Cy_POSIF_HSC_SetHallPatterns()
    • Allows immediate shadow transfer using Cy_POSIF_HSC_UpdateHallPattern()
  5. Quadrature Decoder (APIs prefixed with CY_POSIF_QD_)
    • Configuration structure Cy_POSIF_QD_CONFIG_t and initialization function Cy_POSIF_QD_Init()
    • Get direction of rotation using Cy_POSIF_QD_GetDirection()
  6. MultiChannel Mode (APIs prefixed with CY_POSIF_MCM_)
    • Configuration structure Cy_POSIF_MCM_CONFIG_t and initialization function Cy_POSIF_MCM_Init()
    • Update multichannel pattern in shadow register using Cy_POSIF_MCM_SetMultiChannelPattern()
    • Allows immediate shadow transfer using Cy_POSIF_MCM_UpdateMultiChannelPattern()
  7. User need to call respective init functions to configure POSIF operating mode. e.g to configure POSIF in hall sensor control with multichannel mode call both Cy_POSIF_HSC_Init() and Cy_POSIF_MCM_Init().
  8. Allows to enable and disable interrupt sources and assign to service request node using Cy_POSIF_EnableEvent(), Cy_POSIF_DisableEvent() and Cy_POSIF_SetInterruptNode()

Also, the POSIF block can be configured from the ModusToolbox™ Device Configurator: section_personality_posif
