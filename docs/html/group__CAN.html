Controller Area Network Controller (CAN)
PDL API Reference

General Description

Controller Area Network Controller (CAN) driver for the PSC1M microcontroller family.

CAN driver provides transfer of CAN frames in accordance with CAN specificetion V2.0 B (active). Each CAN node can receive and transmit standard frames with 11-bit identifiers as well as extended frames with 29-bit identifiers. All CAN nodes share a common set of message objects. Each message object can be individually allocated to one of the CAN nodes. Besides serving as a storage container for incoming and outgoing frames, message objects can be combined to build gateways between the CAN nodes or to setup a FIFO buffer. The CAN module provides Analyzer mode,Loop-back mode and bit timming for node analysis.

The driver is divided into five sections:

CAN Global features:
  1. Allows to configure module frequency using function Cy_CAN_Init().
  2. Allows to configure Module interrupt using configuration structure Cy_CAN_NODE_INTERRUPT_TRIGGER_t and function Cy_CAN_EventTrigger().
CAN_NODE features:
  1. Allows to set baud rate by configuration structure Cy_CAN_NODE_NOMINAL_BIT_TIME_CONFIG_t and Baudrate Configuration function Cy_CAN_NODE_NominalBitTimeConfigure().
  2. Allows to configure loop-back mode using fuction Cy_CAN_NODE_EnableLoopBack().
  3. Allows to configure CAN Node analyzer using function Cy_CAN_NODE_SetAnalyzerMode().
  4. Allows CAN node events enable/ disable by enum structure Cy_CAN_NODE_EVENT_t and functions Cy_CAN_NODE_EnableEvent() and Cy_CAN_NODE_DisableEvent().
  5. Provides bit timming analysis, configuration structure Cy_CAN_NODE_FRAME_COUNTER_t and function Cy_CAN_NODE_FrameCounterConfigure().
CAN_MO features:
  1. Allows message object initialization by configuration structure Cy_CAN_MO_t and function Cy_CAN_MO_Config().
  2. Allows transfer of message objects using functions Cy_CAN_MO_Transmit() and Cy_CAN_MO_Receive().
  3. Allows to configure Single Data Transfer and Single Transmit Trial using functions Cy_CAN_MO_EnableSingleTransmitTrial() and Cy_CAN_MO_EnableSingleTransmitTrial().
  4. Allows to configure MO events using function Cy_CAN_MO_EnableEvent().
CAN_FIFO features:
  1. Allows message object FIFO structure by configuration structure Cy_CAN_FIFO_CONFIG_t and functions Cy_CAN_TXFIFO_ConfigMOBaseObject() , Cy_CAN_RXFIFO_ConfigMOBaseObject() and Cy_CAN_TXFIFO_Transmit().
CAN_GATEWAY features:
  1. Provides Gateway mode, configuration structure Cy_CAN_GATEWAY_CONFIG_t and function Cy_CAN_GATEWAY_InitSourceObject().
