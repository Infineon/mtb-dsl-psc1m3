Capture Compare Unit 4 (CCU4)
PDL API Reference

General Description

Capture Compare Unit 4 (CCU4) low level driver for PSC1M family of microcontrollers

The CCU4 peripheral is a major component for systems that need general purpose timers for signal monitoring/conditioning and Pulse Width Modulation (PWM) signal generation. Power electronic control systems like switched mode power supplies or interruptible power supplies, can easily be implemented with the functions inside the CCU4 peripheral.
Each CCU4 module is comprised of four identical 16 bit Capture/Compare Timer slices, CC4y (where y = [0..4]). Each timer slice can work in compare mode or in capture mode.

APIs provided in this file cover the following functional blocks of CCU4:
– Timer configuration, Capture configuration, Function/Event configuration, Interrupt configuration

Note:
  1. SLICE (APIs prefixed with e.g. CY_CCU4_SLICE_)
  2. Module (APIs are not having any prefix e.g. CY_CCU4_)
Timer(Compare mode) configuration:
This section of the LLD provides the configuration structure Cy_CCU4_SLICE_COMPARE_CONFIG_t and the initialization function Cy_CCU4_SLICE_CompareInit().

It can be used to:

  1. Start and Stop the timer. (Cy_CCU4_SLICE_StartTimer(), Cy_CCU4_SLICE_StopTimer())
  2. Update the period, compare, Dither, Prescaler and Passive values. (Cy_CCU4_SLICE_SetTimerPeriodMatch(), Cy_CCU4_SLICE_SetTimerCompareMatch(), Cy_CCU4_SLICE_SetPrescaler(), Cy_CCU4_SLICE_SetDitherCompareValue(), Cy_CCU4_SLICE_SetPassiveLevel())
  3. Enable the slices to support multichannel mode. (Cy_CCU4_SLICE_EnableMultiChannelMode())
Capture configuration:
This section of the LLD provides the configuration structure Cy_CCU4_SLICE_CAPTURE_CONFIG_t and the initialization function Cy_CCU4_SLICE_CaptureInit().

It can be used to:

  1. Configure the capture functionality. (Cy_CCU4_SLICE_Capture0Config(), Cy_CCU4_SLICE_Capture1Config())
  2. Read the captured values along with the status, which indicate the value is latest or not. (Cy_CCU4_SLICE_GetCaptureRegisterValue())
Function/Event configuration:
This section of the LLD provides the configuration structure Cy_CCU4_SLICE_EVENT_CONFIG_t.
It can be used to:
  1. Enable and Disable the events. (Cy_CCU4_SLICE_EnableEvent(), Cy_CCU4_SLICE_DisableEvent())
  2. Configure to start and stop the timer on external events.(Cy_CCU4_SLICE_StartConfig(), Cy_CCU4_SLICE_StopConfig())
  3. Modulation, external load and Gating of the timer output.(Cy_CCU4_SLICE_ModulationConfig(), Cy_CCU4_SLICE_LoadConfig(), Cy_CCU4_SLICE_GateConfig())
  4. Control the count direction of the timer based on the external event. (Cy_CCU4_SLICE_DirectionConfig())
  5. Count the external events.(Cy_CCU4_SLICE_CountConfig())
  6. External Trap. Which can be used as protective feature.(Cy_CCU4_SLICE_EnableTrap(), Cy_CCU4_SLICE_DisableTrap(), Cy_CCU4_SLICE_TrapConfig())
Interrupt configuration:
This section of the LLD provides the function to configure the interrupt node to each event (Cy_CCU4_SLICE_SetInterruptNode())

Also, the CCU4 block can be configured from the ModusToolbox™ Device Configurator: section_personality_ccu4
