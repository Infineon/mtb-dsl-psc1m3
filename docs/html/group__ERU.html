Event Request Unit (ERU)
PDL API Reference

General Description

Event Request Unit (ERU) driver for the PSC1M microcontroller family.

The Event Request Unit (ERU) is a versatile multiple input event detection and processing unit. The ERU module can be used to expand the P-to-P connections of the device: ports-to-peripherals, peripherals-to-peripherals and ports-to-ports. It also offers configurable logic, that allows the generation of triggers, pattern detection and real-time signal monitoring.

The driver is divided into two sections:

Event trigger logic (ERU_ETL):
This section of the LLD provides the configuration structure Cy_ERU_ETL_CONFIG_t and the initialization function Cy_ERU_ETL_Init().
It can be used to:
  1. Select one out of two inputs (A and B). For each of these two inputs, a vector of 4 possible signals is available. (Cy_ERU_ETL_SetSource())
  2. Logically combine the two input signals to a common trigger. (Cy_ERU_ETL_SetSource())
  3. Define the transition (edge selection, or by software) that leads to a trigger event and can also store this status. (Cy_ERU_ETL_SetEdgeDetection() and Cy_ERU_ETL_SetStatusFlag())
  4. Distribute the events and status flags to the output channels. (Cy_ERU_ETL_EnableOutputTrigger())
Output gating unit (ERU_OGU):
This section of the LLD provides the provides the configuration structure Cy_ERU_OGU_CONFIG_t and the initialization function Cy_ERU_ETL_OGU_Init(). It can be used to:
  1. Combine the trigger events and status information and gates the output depending on a gating signal. (Cy_ERU_OGU_EnablePatternDetection(), Cy_ERU_OGU_DisablePeripheralTrigger(), Cy_ERU_OGU_SetServiceRequestMode())

Parameters
eruA constant pointer to Cy_ERU_t, pointing to the ERU base address
Returns
None
Description:
Abstract API, not mandatory to call.
This API is called by Cy_ERU_ETL_Init() or Cy_ERU_OGU_Init() and therefore no need to call it explicitly during initialization sequence. Call this API to enable ERU1 module once again if the module is disabled by calling Cy_ERU_Disable(). For ERU0 module clock gating and reset features are not available.
Related APIs:
Cy_ERU_ETL_Init(), Cy_ERU_OGU_Init(), Cy_ERU_Disable().
