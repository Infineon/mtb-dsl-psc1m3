Synchronous Serial Channel for SPI (SPI)
PDL API Reference

General Description

Synchronous serial channel driver for SPI-like communication.

The SPI driver uses Universal Serial Interface Channel(USIC) module. The USIC module supports multiple data lines for SPI communication.

  1. Full duplex communication with 2 separate lines for transmission and reception.
  2. Half duplex communication with 1 common line shared for transmission and reception.
  3. Dual mode communication with 2 common lines shared for transmission and reception.
  4. Quad mode communication with 4 common lines shared for transmission and reception.

SPI driver provides structures, enumerations and APIs for configuring the USIC channel for SPI communication and also for data transaction.
SPI driver features:

  1. Configuration structure Cy_SPI_CH_CONFIG_t and SPI initialization function Cy_SPI_CH_Init()
  2. Allows configuration of protocol word and frame length using Cy_SPI_CH_SetWordLength(), Cy_SPI_CH_SetFrameLength()
  3. Allows manipulation of data frame at runtime using Cy_SPI_CH_EnableSOF(), Cy_SPI_CH_EnableEOF(), Cy_SPI_CH_EnableSlaveSelect(), Cy_SPI_CH_DisableSlaveSelect()
  4. Provides APIs for transmitting data and receiving data using Cy_SPI_CH_Transmit(), Cy_SPI_CH_Receive(), Cy_SPI_CH_GetReceivedData()
  5. Allows configuration of shift clock using Cy_SPI_CH_ConfigureShiftClockOutput()
  6. Provides enumeration of SPI protocol events using Cy_SPI_CH_STATUS_FLAG_t

void Cy_SPI_CH_InitEx ( Cy_USIC_CH_t *const  channel,
const Cy_SPI_CH_CONFIG_t *const  config,
bool  init_brg 
)
Parameters
channelA constant pointer to Cy_USIC_CH_t, pointing to the USIC channel base address.
configpointer to constant SPI channel configuration data structure.
Refer data structure Cy_SPI_CH_CONFIG_t for detail.
init_brgSelects if the baudrate generator should be configured automatically.
Returns
None
Description:
Initializes the selected SPI channel with the config structure.

Enable SPI channel by calling Cy_USIC_CH_Enable() and then configures
  • Baudrate,
  • Passive data level as active high,
  • Shift control signal as active high,
  • Frame length as 64U,
