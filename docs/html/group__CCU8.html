Capture Compare Unit 8 (CCU8)
PDL API Reference

General Description

Capture Compare Unit 8 (CCU8) low level driver for PSC1M family of microcontrollers

The CCU8 peripheral functions play a major role in applications that need complex Pulse Width Modulation (PWM) signal generation, with complementary high side and low side switches, multi phase control. These functions in conjunction with a very flexible and programmable signal conditioning scheme, make the CCU8 the must have peripheral for state of the art motor control, multi phase and multi level power electronics systems.
Each CCU8 module is comprised of four identical 16 bit Capture/Compare Timer slices, CC8y (where y = [0..4]). Each timer slice can work in compare mode or in capture mode.

APIs provided in this file cover the following functional blocks of CCU8: – Timer configuration, Capture configuration, Function/Event configuration, Interrupt configuration

Note:
  1. SLICE (APIs prefixed with e.g. CY_CCU8_SLICE_)
  2. Module (APIs are not having any prefix e.g. CY_CCU8_)
Timer(Compare mode) configuration:
This section of the LLD provides the configuration structure Cy_CCU8_SLICE_COMPARE_CONFIG_t, Cy_CCU8_SLICE_DEAD_TIME_CONFIG_t and the initialization functions Cy_CCU8_SLICE_CompareInit(), Cy_CCU8_SLICE_DeadTimeInit().

It can be used to:

  1. Start and Stop the timer. (Cy_CCU8_SLICE_StartTimer(), Cy_CCU8_SLICE_StopTimer())
  2. Update the period, compare, Dither, Prescaler and Passive values. (Cy_CCU8_SLICE_SetTimerPeriodMatch(), Cy_CCU8_SLICE_SetTimerCompareMatch(), Cy_CCU8_SLICE_SetPrescaler(), Cy_CCU8_SLICE_SetDitherCompareValue(), Cy_CCU8_SLICE_SetPassiveLevel())
  3. Configure the dead time.(Cy_CCU8_SLICE_SetDeadTimeValue(), Cy_CCU8_SLICE_SetDeadTimePrescaler())
  4. Enable the slices to support multichannel mode. (Cy_CCU8_SLICE_EnableMultiChannelMode())
Capture configuration:
This section of the LLD provides the configuration structure Cy_CCU8_SLICE_CAPTURE_CONFIG_t and the initialization function Cy_CCU8_SLICE_CaptureInit().

It can be used to:

  1. Configure the capture functionality. (Cy_CCU8_SLICE_Capture0Config(), Cy_CCU8_SLICE_Capture1Config())
  2. Read the captured values along with the status, which indicate the value is latest or not. (Cy_CCU8_SLICE_GetCaptureRegisterValue())
Function/Event configuration:
This section of the LLD provides the configuration structure Cy_CCU8_SLICE_EVENT_CONFIG_t.

It can be used to:

  1. Enable and Disable the events. (Cy_CCU8_SLICE_EnableEvent(), Cy_CCU8_SLICE_DisableEvent())
  2. Configure to start and stop the timer on external events.(Cy_CCU8_SLICE_StartConfig(), Cy_CCU8_SLICE_StopConfig())
  3. Modulation, external load and Gating of the timer output.(Cy_CCU8_SLICE_ModulationConfig(), Cy_CCU8_SLICE_LoadConfig(), Cy_CCU8_SLICE_GateConfig())
  4. Control the count direction of the timer based on the external event. (Cy_CCU8_SLICE_DirectionConfig())
  5. Count the external events.(Cy_CCU8_SLICE_CountConfig())
  6. External Trap. Which can be used as protective feature.(Cy_CCU8_SLICE_EnableTrap(), Cy_CCU8_SLICE_DisableTrap(), Cy_CCU8_SLICE_TrapConfig())
Interrupt configuration:
This section of the LLD provides the function to configure the interrupt node to each event (Cy_CCU8_SLICE_SetInterruptNode())
