Flash Driver (FLASH)
PDL API Reference

General Description

Flash driver for PSC1M microcontroller family.

Flash is a non volatile memory module used to store instruction code or constant data. The flash low level driver provides support to the following functionalities of flash memory.

  1. Provides functions to program and verify pages. ( Cy_FLASH_ProgramPage(), Cy_FLASH_ProgramPages() Cy_FLASH_ProgramVerifyPage() )
  2. Provides functions to write and verify blocks. ( Cy_FLASH_WriteBlocks(), Cy_FLASH_VerifyBlocks() )
  3. Provides functions to read data in terms of word and blocks. ( Cy_FLASH_ReadBlocks(), Cy_FLASH_ReadWord() )
  4. Provides function to erase page. ( Cy_FLASH_ErasePage() )

◆ Cy_FLASH_STATUS_t

enum Cy_FLASH_STATUS_t

Defines the status of flash, to verify the flash related API calls.

Use type Cy_FLASH_STATUS_t for this enum. The members defines the respective masked status bits of NVMSTATUS register.

Enumerator
CY_FLASH_STATUS_OK 

Flash related operation was successfully completed.

CY_FLASH_STATUS_BUSY 

Cannot execute the flash request because another operation is in progress.

CY_FLASH_STATUS_SLEEP_MODE 

Flash is in sleep mode.

CY_FLASH_STATUS_VERIFY_ERROR 

Flash reported a verification failure.

CY_FLASH_STATUS_ECC1_READ_ERROR 

Flash reports a single bit failure, and it is automatically corrected.

CY_FLASH_STATUS_ECC2_READ_ERROR 

Flash reported at least two bit failure.

CY_FLASH_STATUS_WRITE_PROTOCOL_ERROR 

Write/Verify operation on a block is failed due to protocol violations or write protected sectors.

◆ Cy_FLASH_HARDREAD_LEVEL_t

enum Cy_FLASH_HARDREAD_LEVEL_t

Defines hard read levels for strict data verification.

Use type Cy_FLASH_HARDREAD_LEVEL_t for this enum. These hardread levels provide some margin to ensure that the data is really programmed with suitably distinct levels for written and erased bits.

Enumerator
CY_FLASH_HARDREAD_LEVEL_NORMAL 

No hardread level verification enabled (Normal read)

CY_FLASH_HARDREAD_LEVEL_WRITTEN 

Enables strict margin compare for written data cells.

CY_FLASH_HARDREAD_LEVEL_ERASED 

Enables strict margin compare for erased data cells.

uint32_t  num_pages 
)
Parameters
addressPointer to the starting address of the flash page from where the erase starts
num_pagesNumber of pages to be erased.
Range: [1 to (flash size / 256)]
Returns
Status of operation (NVM_STATUS)
Description:
Erases a set of flash memory pages.

Erase starts from the specified address. It erases a maximum number of num_pages flash pages. The maximum erasable pages are limited to microcontroller flash size. It sets NVMPROG register to continuous page erase mode before erase and resets it action back to normal state on completion. Call Cy_FLASH_GetStatus() after calling this API to verify the erase operation.
Note:
Flash will be in busy state during erase operation. Hence no operations on flash are allowed until it completes.

Description:
Performs verification of written data blocks.

After calling Cy_FLASH_WriteBlocks() API, calling this API will verify the correctness of written blocks.
